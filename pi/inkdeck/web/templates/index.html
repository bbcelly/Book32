    Saved for later: InkDeck joins it when it's in range, for example after a move. When no saved network is in range, InkDeck starts its own InkDeck-Setup network so you can choose one from a phone.

    Sleep and shutdown

    The device sleeps after a period without input; any button wakes it.

    Wi-Fi turns off while asleep unless you keep it on while reading.
